      データ管理

      GitHub に暗号化して保存

      対象リポジトリへの読み書き権限を持つ GitHub トークンと、16バイト以上の暗号化パスワードを入力します。通常、入力内容は画面を開いている間だけ保持します。「この端末で記憶」を選ぶと、復号用の鍵と GitHub トークンをこのブラウザーに保存します。このブラウザーを使える人は接続できるため、自分専用の端末で利用してください。パスワードを忘れると GitHub 上のデータを復元できません。

      暗号化パスワードを忘れた場合

      この端末に記録が表示されている場合は、先に下の「バックアップを書き出す」で保存してください。バックアップは暗号化されていないため、自分だけが見られる場所に保管してください。新しいパスワードと GitHub トークンを上に入力し、次の操作でこの端末の記録を新しいパスワードで保存できます。GitHub にしかない古い記録は復元できません。

      記録はこのブラウザー内に保存されます。別の端末で使うには GitHub に保存し、そちらで読み込んでください。定期的なバックアップもおすすめします。

      既存の記録を残して追加します。同じ試験・科目は重複を避けてスキップします。

      データ管理

      GitHub に暗号化して保存

      対象リポジトリへの読み書き権限を持つ GitHub トークンと、16バイト以上の暗号化パスワードを入力します。入力内容は画面を開いている間だけ保持します。パスワードを忘れると復元できません。

      記録はこのブラウザー内に保存されます。別の端末で使うには GitHub に保存し、そちらで読み込んでください。定期的なバックアップもおすすめします。

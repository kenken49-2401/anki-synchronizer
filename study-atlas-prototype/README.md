# Study Atlas プロトタイプ

Anki Atlasへの統合を検討するための独立した試作品です。既存リポジトリや公開サイトには反映していません。架空データで画面を試すか、Google Sheets APIで自分のシートを直接読み書きできます。

## 起動

このディレクトリで `python -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000/` を開きます。Google OAuthの承認済み生成元にも同じ `http://127.0.0.1:8000` を登録してください。HTTPSの公開サイトで使う場合はそのサイトの生成元を登録します。

## 接続の準備

1. Google CloudのプロジェクトでGoogle Sheets APIを有効にします。
2. Google Auth PlatformでOAuth同意画面を設定し、公開前のテスト中は自分のGoogleアカウントをテストユーザーに追加します。
3. OAuthクライアントIDを「ウェブアプリケーション」として作成し、アクセスするサイトの生成元（例: `http://127.0.0.1:8000`）を承認済みJavaScript生成元に追加します。
4. アプリの「接続・設定」にクライアントIDとスプレッドシートIDを入力し、スプレッドシートへのアクセスを許可します。スプレッドシートIDはURLの `/d/` と `/edit` の間の文字列です。

クライアントIDは秘密鍵ではありません。OAuthクライアントシークレットをアプリやリポジトリに入れないでください。アクセストークンはブラウザのメモリ内にのみ保持し、読み書きはブラウザからGoogle Sheetsへ直接行います。スコープはスプレッドシートの読み書きです。Google CloudのプロジェクトやOAuth設定はこの試作品からは作成しません。

## 現在の範囲

- `必勝1`, `必勝2`, `実戦1`, `本レ2`, `OP2`, `過去問` の大問表を対象に、点数・平均・自己採点・配点を読み込み、入力セルを編集します。合計行や数式セルは編集しません。
- 分野タグと模試実施日を `StudyAtlas_分野` に記録し、得点率・平均との差・日付別推移を算出します。最初の保存時にシートを作成します。タグ変更は末尾に追記し、最後の記録を採用します。
- 新しい日付別・科目別時間は `StudyAtlas_勉強時間` に保存します。既存の `夏休み勉強時間` の値も一覧に表示・編集できます。既存の日付には年がないため推測しません。元表の集計列は編集しません。
- 保存前に対象セルの値・数式を再取得して、数式または読み込み後に変更されたセルへの書き込みを拒否します。読み取りと書き込みの間の同時編集を完全に防ぐ仕組みではありません。点数保存とタグ保存は別リクエストなので、一方が失敗した場合は再読み込みして確認してください。
- この段階では指定した形式の表に限ります。他のレイアウトの表、模試の新規作成、長期の重複・競合管理、全科目・全期間の統合、Ankiとの統合は今後の課題です。Google API接続は各自のOAuth設定が必要で、ライブ接続は設定後に実機確認してください。

参考: [Google Identity Services のトークン方式](https://developers.google.com/identity/oauth2/web/guides/use-token-model)、[Sheets API 値の読み書き](https://developers.google.com/workspace/sheets/api/guides/values)。
